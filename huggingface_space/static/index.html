About the Model

Dataset

Trained on the LC25000 dataset, featuring 10,000 high-resolution histopathological images of colon tissue, split into Adenocarcinoma and Benign categories.

Architecture

Built on EfficientNetB3 with Transfer Learning. The model uses 10.7M pre-trained parameters and a custom classification head for medical precision.

Performance

Achieved 99.4% validation accuracy. Optimized with Adam (LR=1e-4) and advanced callbacks like EarlyStopping and Learning Rate Reduction.
